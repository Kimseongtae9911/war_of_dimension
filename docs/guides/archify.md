# Archify 작업 지침

VAFK의 프로젝트 지침 구조를 참고하며, 프로젝트에 복사한 Archify 2.16을 사용한다.

- 구조·API 호출·네트워크·데이터 흐름·자원 수명·상태 전이가 변경되면 관련 코드와 다이어그램을 대조한다. 해당 영향이 없는 수정은 재생성하지 않고 이유를 검증 기록에 남긴다.
- 구현 자료는 현재 코드와 검증을 근거로 작성한다. 설계안을 작성하면 현재 구현과 다른 파일에 미구현 상태를 표시한다.
- `docs/diagrams/<주제>/`에 JSON·HTML·README를 둔다. README에 근거, 버전, 재생성 명령과 검증 상태를 기록한다.
- 프로젝트 스킬 `.agents/skills/archify/SKILL.md`의 `validate` → `deliver` → `visual-check` 절차를 따른다. 기존 JSON을 수정하고 HTML을 재생성한다.
- 실패한 산출물이나 이전 HTML을 최신 성공 결과로 제시하지 않는다. 자동 검사와 실제 시각 점검을 구분한다.
- 설명은 한글로 작성한다. 한국어를 지원하지 않는 고정 Viewer UI는 영어라는 점을 기록한다.
