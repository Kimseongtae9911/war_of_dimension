2. 분석한 원인

플레이어와 미니언이 지면 높이를 구할 때마다 메시 처음부터 검색했습니다. 같은 위치라도 대부분의 삼각형을 다시 계산했습니다.

// 개선 전 흐름을 줄인 의사 코드
for (triangle : mesh) {
    if (RayHits(triangle))
        return firstHit;
}

3. 해결 방식

로드·높이 정렬 후 4단위 XZ 격자를 만들고, 해당 셀과 전역 후보를 원본 ID 순으로 병합합니다. tick 조회는 할당·잠금 없이 읽기만 합니다.

// 개선 후 흐름을 줄인 의사 코드
for (id : index.Query(x, z, mesh.size())) {
    if (RayHits(mesh[id]))
        return firstHit;  // 기존 순서와 수식
}

경계에는 여유를 두고 수치적으로 불안정한 면은 전역 후보로 유지합니다. 비수직 Ray·극단 Y·무효 인덱스는 전체 검색합니다. 공간 검색 흐름도
