1. 결과

공간 후보를 유지하고 삼각형의 불변 계산을 재사용했습니다. 실제 서버 비교 30/30회 성공. CPU 중앙값은 1매치에서 증가했습니다. 실행 간 변동과 함께 판단해야 합니다. 1매치 CPU 상승은 계측 끔 대조에도 남아 있어 전체 CPU 개선 완료로 판단하지 않습니다.

2. 분석한 원인

셀로 후보를 줄인 뒤에도 같은 삼각형의 법선·변·내적·분모를 매 Ray마다 계산했습니다.

// 기존 RayCast의 반복 계산
normal = Normalize((v2 - v1).Cross(v3 - v1));
edge1 = v2 - v1; edge2 = v3 - v1;
invDenom = 1.0f / (dot11 * dot22 - dot12 * dot12);
